
# 🏠 House Price Prediction

A machine learning project that predicts house prices based on features such as location, size, number of rooms, and more, using the **Boston Housing Dataset**. Includes a web interface for quick testing and deployment.

## 🔍 Project Overview

- Trained regression models to estimate property prices using real housing data
- Explored and visualized features affecting house prices
- Built an interactive UI using HTML and deployed via GitHub Pages

## 🚀 Live Demo

🔗 [Try the Web App](https://flashingcards.github.io/House-Prize-Prediction/)

## 🧠 Machine Learning Techniques

- Linear Regression
- Data preprocessing (normalization, handling nulls)
- Evaluation using metrics like RMSE and R²

## 📊 Dataset

The [Boston Housing Dataset](https://scikit-learn.org/stable/datasets/toy_dataset.html#boston-house-prices-dataset) was used, containing 506 samples and 13 features such as:

- CRIM: Crime rate
- RM: Average rooms per dwelling
- LSTAT: % lower status population
- PTRATIO: Pupil-teacher ratio
